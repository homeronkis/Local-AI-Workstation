# Local AI Workstation

Автономный комплекс локального искусственного интеллекта для Windows, оптимизированный под **NVIDIA GeForce RTX 3060 (12GB)**, **32GB RAM** и **Intel Core i5-12400F**.

Работает на 100% локально, оффлайн, без абонентской платы и без передачи данных во внешние облака.

---

## 🚀 Возможности

1. **Интеллектуальный ассистент (Qwen 2.5 7B на GPU):**
   - Полноценная замена облачным ИИ для написания кода, переводов, редактуры и ответов на вопросы.
   - Задействует ядра CUDA вашей RTX 3060, полностью загружается в 12 ГБ VRAM (~5.1 ГБ занято, >7 ГБ буфера).
   - Скорость генерации: до 40–50 слов/сек.

2. **Приватный анализ документов (PDF, TXT):**
   - Локальная загрузка договоров, конспектов и отчетов.
   - Поиск фактов, условий, штрафов и составление саммари без риска утечки коммерческих/личных данных.

3. **GPU-транскрибатор речи (Faster-Whisper):**
   - Распознавание аудио и видео (MP3, WAV, M4A, MP4, MKV) в текст с таймкодами и пунктуацией на базе CTranslate2.
   - Обработка в разы быстрее реального времени.

4. **Мониторинг ресурсов в реальном времени:**
   - Отображение занятой видеопамяти (VRAM), температуры GPU, загрузки CPU и ОЗУ.

---

## 🛠️ Стек технологий

- **Backend:** Python 3.11, FastAPI, Uvicorn, Faster-Whisper, PyPDF, Requests, Psutil
- **Frontend:** Нативный адаптивный веб-интерфейс (HTML5, CSS3, ES6 JavaScript)
- **AI Core:** Ollama (LLaMA-server под CUDA 12/13), модель `qwen2.5:7b`

---

## ⚡ Запуск

Дважды кликните по файлу `start.bat` (или ярлыку на рабочем столе). Веб-интерфейс откроется автоматически по адресу:
```
http://127.0.0.1:8000
```
